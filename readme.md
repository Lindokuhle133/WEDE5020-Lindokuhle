# WEDE5020 Portfolio of Evidence (POE) - Part 3

## Project Overview
This repository contains the final web development project for WEDE5020. The website consists of five responsive HTML, CSS, and JavaScript pages designed to provide an interactive user experience, dynamic content loading, and robust search functionality.

---

## Changelog & Part 3 Updates

### Version 3.0 (Part 3 Implementation)
* *JavaScript Enhancements:* Implemented interactive elements, dynamic content loading, and form validation across all five web pages.
* *Search Engine Optimization (SEO):* Added On-Page SEO meta tags, descriptive title tags, image alt text, a root robots.txt file, and a fully structured sitemap.xml file.
* *Form Functionality:* Developed validation and interactive responses for both enquiry.html and contact.html forms.
* *Deployment:* Deployed the website live via GitHub Pages/Netlify.

### Version 2.0 (Part 2 Feedback Edits)
* Refined CSS layout structures and improved mobile-friendliness based on academic feedback from Part 2.
* Enhanced navigation and internal linking between the five pages.
